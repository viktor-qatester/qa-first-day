# Рабочий стол QA — первый интерактивный этап

## Цель этапа

Постепенно перенести День 1 из карточного сценария в рабочее пространство. Первый этап уже связан с основным сценарием и передаёт прогресс дальше, не создавая отдельную учебную ветку.

## Принятое направление

- Основа — виртуальный рабочий компьютер тестировщика.
- Центральный объект — текущая рабочая задача, а не список уроков.
- Команда общается через рабочий чат.
- Требования, ShopPoint, DevTools, Swagger, SQL и Jira представлены как инструменты.
- Инструменты открываются по контексту, а не по учебной нумерации.
- Диалоги и карточки используются внутри конкретного инструмента; пользователь выполняет работу из контекста задачи.
- Следующий этап продолжает существующий День 1 с проверки оформления заказа.

## Граница текущего этапа

В `dist/concept.html` пользователь называет себя, принимает SP-214, уточняет правило для нового клиента, отмечает чек-лист, проверяет справочник промокодов и сравнивает сумму в ShopPoint с требованиями. После выбора он продолжает основной сценарий с шага проверки повторной отправки заказа.

Проверка справочника и корзины учебные: они показывают заранее подготовленные данные, а не подключаются к настоящему сайту, API или базе данных. Рабочие инструменты открываются последовательно, чтобы новичок видел, откуда берётся вывод.

Промежуточный прогресс рабочего стола хранится отдельно в браузере. При переходе его ключевые решения и баллы записываются в формат существующего прохождения. Если уже было сохранено другое прохождение, оно сохраняется в браузере как резервная копия.

## Критерии решения

Проверить по завершённому пути на телефоне и ноутбуке:

1. Возникает ли ощущение настоящего рабочего пространства?
2. Понятно ли, что делать без отдельной инструкции?
3. Не перегружен ли экран для новичка?
4. Открываются ли инструменты только после необходимых шагов?
5. Передаются ли баллы и выбранный вариант в существующий сценарий?
6. Остаётся ли возможность вернуться к карточной версии?

## Ограничения

- Приложение остаётся статическим HTML/CSS/JavaScript.
- Аккаунты, серверное сохранение и аналитика не добавляются.
- Визуальный язык самостоятельный; фирменное оформление других платформ не копируется.
