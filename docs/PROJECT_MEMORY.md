# Память проекта

## Состояние на 28 сентября 2026

- Продукт: мобильный учебный симулятор для новичков без опыта.
- Текущий этап: Спринт 01, углубление первого дня.
- Решение: не начинать День 2 до проверки расширенного Дня 1.
- Основной разбор отзывов: `docs/FEEDBACK_ANALYSIS.md`.
- План спринта и критерии: `docs/SPRINT_01.md`.
- Постоянные методические правила и инструменты: `docs/QA_SIMULATION_KNOWLEDGE_BASE.md`.
- Специализированный навык: `design-realistic-qa-simulations`.
- Следующий продуктовый шаг: опубликовать проверенную версию и собрать второй круг отзывов.

## Визуальный эксперимент

- Создан отдельный прототип `dist/concept.html`: виртуальный рабочий стол QA.
- Он не заменяет основной сценарий и доступен со стартового экрана.
- Проверяем рабочую метафору: задача, чат команды и инструменты вместо последовательности учебных карточек.
- Критерии оценки зафиксированы в `docs/DESIGN_CONCEPT_WORKSPACE.md`.

## Неизменные ограничения

- Статическое приложение без аккаунтов и зависимости от ChatGPT.
- Имя и прогресс хранятся только локально в браузере пользователя.
- Интерфейс работает на телефоне и ноутбуке.
- Каждое изменение проходит автоматические проверки, commit, push и проверку публикации.
