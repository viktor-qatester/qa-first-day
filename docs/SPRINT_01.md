# Спринт 01 — углубление первого дня

## Цель

Сделать первый рабочий день длиннее и реалистичнее, не переходя пока ко второму дню. Целевая продолжительность прохождения — 45–60 минут.

## В объёме

- 26 последовательных экранов.
- Постановка задачи через скоуп сборки.
- Чек-лист до основной проверки.
- Проверка настройки промокода как источника истины.
- Подготовка DevTools до действия.
- Разбор UI, Network, API и БД без ложного вывода о «дубликате».
- Контракт Swagger и различие HTTP/бизнес-ошибки.
- Безопасный SQL.
- Уточнение воспроизведения у разработчика.
- Ретест, короткий регресс и рекомендация по релизу.
- Нейтральные варианты ответов до выбора.

## Критерии приёмки

- Имя участника сохраняется только в его браузере и используется в обращениях.
- Новое прохождение полностью сбрасывает прогресс.
- Правильный маршрут даёт 100% при максимуме 40 баллов.
- Этап рабочего стола передаёт имя, уже принятые решения и баллы в основной маршрут с шага проверки оформления заказа.
- Если есть другое сохранённое прохождение, переход в новый маршрут сохраняет его резервную копию в браузере.
- Если браузер запрещает localStorage, приложение предупреждает об ограничении и оставляет прохождение доступным до закрытия вкладки.
- Smoke-тест проверяет ключевые методические исправления.
- E2E проходит весь маршрут, проверяет итог и восстановление прогресса.
- E2E проверяет отклонение небезопасного SQL, принятие эквивалентной безопасной выборки и продолжение из рабочего стола.
- Карточки выбора не перекрывают текст на мобильной ширине.
- GitHub Actions зелёный до публикации.

## Не входит

- Второй рабочий день.
- Аккаунты, серверное хранение прогресса и аналитика пользователей.
- Настоящие Jira, база данных или API.
- Расширенная система достижений.
